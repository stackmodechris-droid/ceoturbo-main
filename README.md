# CEOTurbo

CEOTurbo is a Next.js portfolio and service website for showing website builds, SEO work, Meta ad creative, reviews, and branded business products.

## What is included

- Homepage portfolio tabs for 20 website previews and 22 ad designs
- Clickable website preview cards with live destinations
- Full-size gallery viewer for proof assets
- SEO, website, Meta ads, business card, shirts, reviews, and booking pages
- Responsive mobile and desktop layouts
- Accessibility-focused navigation, tabs, galleries, and modal behavior
- Playwright and axe coverage for core public routes

## Development

Install dependencies:

```bash
npm install
```

Run the local site:

```bash
npm run dev
```

Run production verification:

```bash
npm run verify
```

Run browser tests:

```bash
npm run test:e2e
```

## Stack

- Next.js
- React
- TypeScript
- Playwright
- axe-core
